# Seven Dice — Карты и переходы

Модуль для **Foundry VTT 14**: библиотека карт, визуальный редактор двусторонних переходов и схема локаций. Текущая версия — **1.7.0**. Форматы документов проверены на Foundry **14.370**.

## Возможности

- Библиотека сцен с поиском, папками, метками и избранным.
- Загрузка изображений и создание сцен с настройками сетки, освещения и зрения.
- Двусторонние переходы между сценами: выходы и места появления настраиваются прямо на изображениях.
- Несколько проходов между одной парой сцен.
- Переходы внутри одной сцены, например между этажами на общем изображении.
- Ручная схема локаций с предложением уже связанных сцен; обзор всех сохранённых связей.
- Перемещение схемы мышью на пустом месте и отдельное перемещение блоков.
- Создание карты из схемы с переходом к её редактированию.
- Альтернативные фоны одной сцены с сохранением координат переходов.
- Черновики, отмена правок, проверка связей и резервные копии настроек.

## Установка

1. Помести содержимое репозитория в папку `Data/modules/margora-passages` своего Foundry.
2. Проверь, что `module.json` находится непосредственно в этой папке.
3. Перезапусти Foundry VTT.
4. В своём мире включи **Seven Dice — Карты и переходы** в управлении модулями.
5. Открой список сцен и нажми **Seven Dice — Карты и переходы**.

Если пользуешься Git, находясь в папке `Data/modules`, выполни:

```sh
git clone https://github.com/sdsevendice/Seven-dice-map.git margora-passages
```

Это ручная установка. Отдельный установочный манифест для автоматической установки по ссылке пока не опубликован.

## Первый переход

1. Открой исходную карту и нажми **Добавить переход**.
2. Выбери вторую карту.
3. Поставь выходы на дороги или двери, а зелёные места появления — на свободный участок внутри соответствующей карты.
4. Нажми **Сохранить связь**. Сохраняются оба направления.
5. Проверь токеном вход в область обычным движением. Для переходов игроков между сценами должен быть подключён мастер.

На схеме размещение блоков меняет только её вид. Чтобы создать игровой проход, открой редактор выбранной карты.

## Совместимость

Публичное название модуля изменено, но внутренний идентификатор **margora-passages** сохранён. Это позволяет использовать прежние настройки, переходы и локальные черновики. Папку установленного модуля переименовывать не нужно.

Расстановка схемы, избранное и черновики сохраняются локально для конкретного мира и пользователя. Рабочие переходы сохраняются в сценах Foundry. Изображения, игровые карты и данные миров в репозиторий не включены.

## Проверки

Без дополнительных пакетов, с установленным Node.js:

```sh
npm test
```

В репозитории находятся 85 проверок логики. Для версии 1.7.0 также выполнены 103 сценария интерфейса в отдельном браузере и проверка форматов документов классами Foundry 14.370. Проверка в отдельном браузере не заменяет пробу автоматического перемещения в игровом мире.
